# 屏幕与实体按键的语音入口

主屏下方提供常驻「按住说话」按钮，实体 **BOOT** 也保留同样的按住录音方式。

| 状态 | 屏幕按钮 | 操作 |
|---|---|---|
| 就绪 | 按住说话 | 按住录音，松开提交 |
| 录音 | 松开提交 | 触屏时滑出按钮取消；BOOT 录音时松开 BOOT 提交 |
| 等待／回答 | 按住打断 | 取消旧播放并开始新一轮 |
| 未连接 | 连接后按住说话 | 先确认 Wi-Fi、Mac 桥接与原生语音；按住时显示连接进度，松开后不会在稍后偷偷录音 |

按钮不接收抚摸或上划设置的事件；圆脸仍可抚摸，底部设置入口仍可使用。字幕关闭也不会隐藏语音按钮或操作提示。

触屏和 BOOT 同时按住时，以 **BOOT** 为准：手指松开不会提前提交，松开 BOOT 才结束这一轮；残留手指必须先抬起，才能开始下一轮。触屏滑出后再划回不会重新开始录音，需抬起后重新按住。少于 100 ms 的短按不提交，录音上限仍为 55 秒。

## 升级保护

公开安装器新增支持已确认、CRC 正确且实际选择 ota_0 的记录。仍会拒绝活动 ota_1、待确认、损坏或回滚记录，写前继续逐字节核对启动元数据。全 FF 空白记录也拒绝：ESP-IDF 第一次启动会初始化它，不能把会变化的元数据当作稳定恢复基线。本轮当前设备使用已确认的 ota_0 路径。
