# 用实体 BOOT 与小糖说话

语音由实体 **BOOT** 控制，屏幕下方只显示提示，没有可点击的说话按钮。触屏继续用于抚摸、唤醒、上划设置和调整音量。

| 状态 | 屏幕提示 | 操作 |
|---|---|---|
| 就绪 | 按住 BOOT 说话 | 按住实体 BOOT 录音 |
| 录音 | 松开 BOOT 后提交 | 松开 BOOT 提交 |
| 等待／回答 | 按住 BOOT 打断 | 取消旧回复并开始新一轮 |
| 未连接 | 语音连接中 | 检查 Wi-Fi、Mac 桥接与原生语音 |

字幕模式不会隐藏 BOOT 操作提示。少于100 ms的短按不提交，单次录音上限55秒；断网时松开不会稍后自动开麦。

## 设计反馈与验收

实验版曾同时提供触屏按钮与 BOOT；参考设备使用者已确认两种方式均能完成语音对话，但认为圆屏按钮过小、不易按准，因此选择实体 BOOT 作为语音入口。最终版移除该触屏按钮和其录音事件，保留非交互提示。实验记录保留在 [历史台架记录](touch-entry-validation.json)，不作为最终版验收。

最终版构建、回归和设备状态以 [验收说明](VALIDATION.md) 及 [本轮检查](boot-entry-validation.json) 为准。屏幕图从设备导出，导出时隐藏字幕与配对码。

## 升级保护

安装器支持已确认、CRC正确且实际选择ota_0的启动记录，写前核对元数据，仅写应用槽。拒绝活动ota_1、待确认、损坏或回滚记录，以及首次启动可能变化的全FF空白记录。升级前须保存并验证完整私人备份。

## 下一版表情与字幕预览（开发中）

本地运行 `npm run preview` 后访问 <http://127.0.0.1:8877>：可切换九种状态，点圆脸看好奇、横向拖动看开心，上划或点底部短横打开预览设置。按住屏幕外侧的模拟BOOT或空格键，松开后经历思考／回答；再次按住打断。预览不调用账户、不录音、不播放声音。

上划进入设置，选择「通话字幕」；页面下方的「试读字幕」提供中文、英文、中英与emoji、空文本和长文本固定示例。预览只在本机浏览器保存字幕模式，与设备设置独立。

| 模式 | 显示行为 |
|---|---|
| 完整 | 显示当前收到的最多320字节窗口，可在文字区域上下滚动；不提供整段回答历史 |
| 简洁（默认） | 截取第一句，最多显示两行；保留完整UTF-8字符 |
| 关闭 | 隐藏对话正文，保留BOOT、连接、必要错误和本地互动提示 |

固件用独立NVS键保存模式；旧字幕开启迁移为简洁、关闭迁移为关闭，不扩大旧配置结构。保存失败时维持先前模式并显示重试提示。新轮次、打断或断线会清除旧文字；旧轮次延迟到达的文字被丢弃。底部设置短横与完整字幕滚动区域分开。

动画几何和字幕示例均由实际C代码导出；修改后运行 `npm run preview:export`，测试会检查二者一致。无声网页中的等待／回答时长是演示用，不是设备时延测量。真实设备仍运行v0.1.1，当前阶段没有刷机；设备重启保存、圆屏滚动手感、脱敏导出和语音回归仍待实机验收，发行包尚待实施。
