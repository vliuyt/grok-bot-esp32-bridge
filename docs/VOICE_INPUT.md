# 用实体 BOOT 与小糖说话

按住实体 **BOOT** 录音，松开提交；回答时再次按住，清除旧播放并开始新问题。触屏用于抚摸、唤醒、设置和字幕阅读。没有触屏录音按钮。

| 状态 | 操作与反馈 |
|---|---|
| 就绪 | 按住 BOOT 说话 |
| 录音 | 松开 BOOT 后提交 |
| 等待／回答 | 按住 BOOT 打断 |
| 录音太短 | 不提交，提示重新说一次 |
| 等待较久 | 12秒后提示还在等；持续有响应／工具进展时延长等待 |
| 本轮失败 | 清楚说明没收到回复、未听清、无声音或回答失败；再次BOOT开始新轮 |
| 登录／连接异常 | 提示在Mac检查登录，或等待连接恢复；不重放录音或重交任务 |

少于100 ms的短按不提交，单次录音上限55秒。字幕关闭也保留BOOT、连接和必要失败提示。夜间先把设备音量调低，再由使用者按键试说；自动测试不播放声音。

如果没有回答，先停止重复试说，保留当轮现象。Mac本地状态接口提供有界的原生事件顺序：当前会话及上个断开会话的诊断仅保存在内存，最多各96条，不含音频、对话正文、账户／原始会话ID或任意错误消息。就绪只说明连接状态，仍需确认设备实际回答。

状态接口的`outputAudio`只统计重采样后数据的样本数、RMS和峰值，不保存或修改录音。它能区分未收到数据、静音数据和有幅度的数据；设备消费帧数与这些电平均不能单独证明扬声器已经出声。

设备上行在24kHz重采样后做有限增益补偿：轻声最多放大4倍（约12dB），峰值立即降低增益，按500ms时间常数恢复；已足够响的峰值保持至少原幅度。每次按BOOT使用新包络，不保留录音，不改硬件麦克风增益或扬声器音量。网页麦克风路径独立。`lastInputDb`仍表示设备原始电平，`inputAudio`表示送云端的数值电平，断开后保留一份`previousInputAudio`。增益无法修复环境噪声、遮挡或云端停滞，连续真人验收仍以实际记录为准。

本开发分支调整了音量刻度，并放大返回／翻段目标，支持设置和阅读页右滑返回。升级保留原实际响度，屏幕百分比可能变化；不统一要求使用10%～20%。具体操作与旧刻度关系见[圆屏操作说明](UI_USABILITY.md)。

精确计算会优先交给小糖原有任务能力，用代码或计算器核算后回答，可能比闲聊稍慢。请等本轮结果完成，避免重复按键提交同一道题；没有结果时不会自动重交任务。这是设备会话的模型指导，实际工具选择和答案仍需验证。开发验收曾出现题目123×45已正确识别却直接回答5400，现已加入这项指导；无声任务验证得到5535，真人复验见验收记录。

## 长回答怎么读

完整与简洁模式的主屏均显示28px首句概览。点真实字幕进入30px独立阅读页：

1. 用大尺寸「上一段／下一段」切换，段内上下滚动。
2. 等待加载时保留当前文字，3秒无结果可点「点此重试」；这里只重试阅读请求。
3. 进入阅读时固定当前回答版本。显示「回答中」时，后续增长不会使页面自动跳动；返回再进入可刷新。
4. 按BOOT会回主屏并开始新问题。返回、字幕关闭、新轮次、取消和断线使旧页面失效。

Mac仅在内存保存当前轮最多24KiB文字，以及一份最多24KiB的阅读快照。超限会显示「后续文字未保存」；不形成设备历史。每段最多300字节，中文和emoji保持完整UTF-8字符。

| 字幕模式 | 显示 |
|---|---|
| 完整／简洁 | 主屏首句两行，点击进入分页阅读 |
| 关闭 | 清除设备对话正文与阅读状态，保留必要状态提示 |

支持能力由双方协商。新桥接配旧固件仍发送原短字幕；新固件配旧桥接只滚动原窗口，不显示无效翻段入口。模式仍用独立NVS键保存，保存失败维持先前值。原生Bot历史按既有流程保存；本地阅读缓存不额外写盘。

## 无声预览与升级

运行 `npm run preview`，访问 <http://127.0.0.1:8877>，切换「试读字幕」后点击圆屏文字，试用翻段、滚动和返回。点圆脸好奇、横向抚摸开心、上划设置；模拟BOOT或空格只演示状态，不录音、不连接账户、不播放声音。动画和固定字幕从真实C代码导出，修改后运行 `npm run preview:export`。

升级前保存并验证完整私人8MiB备份。保护安装器核对同一设备、镜像／源码摘要、原分区布局和已确认ota_0启动元数据，只写原应用槽。它拒绝活动ota_1、待确认／损坏记录、引导变化及全FF空白记录；不改账户、网络、配对或设置。
