# v0.1.0 · 小糖 ESP32-S3 AI 陪伴宠物（源码预览版）

这是首次公开的源码版本：让 Waveshare ESP32-S3-Touch-AMOLED-1.43C 成为一个有本地小动作、能回应抚摸、可按住说话的圆屏陪伴宠物。Mac 常驻桥接已有 Grok Bot，保留其原生声音、上下文及任务通道。

## 本版包含

- 独立 ESP-IDF 固件：宠物行为、经典粉色双眼 UI、音频队列、设置及休眠策略。
- Mac 原生语音桥接：16 kHz 设备音频、TLS 局域网配对、轮次取消和同次通话任务历史回流。
- Wi-Fi 发现与回退、USB 配网、带屏幕六位码认证的限时 BLE 配网实现。
- 自包含 USB 工具、每位用户自己的完整备份与受限应用槽恢复、可配置 Bot／Node 的可选登录服务。
- 中文从零指南、英文项目入口、架构与协议、验收边界、贡献指南、安全政策和测试工作流。

## 使用前请读

1. 正常登录 Grok Bot App，先验证 Mac 原生语音，再接设备。
2. 固件仅支持明确的 1.43C 板型与文档中的兼容分区／默认 OTA 状态；不会给任意出厂固件自动改分区。
3. 本次只发布源码，GitHub 自动生成的 Source code 压缩包不是可刷固件；请按指南自行构建。
4. 不包含 App、账号、密钥、设备备份、录音或作者私有工作历史。
5. 原生接口是实验性的内部契约，后续 App 版本可能需要适配；此项目与相关厂商无隶属关系。

## 验证

- 公开源码 ESP-IDF 6.0.1 独立构建通过，应用 2,287,568 字节。
- 构建后主机测试 **82/82，零跳过**；干净克隆未构建时 **79 通过、3 项目标依赖检查明确跳过**。
- 参考设备曾完成十轮语音、37.1 秒连续回答、Wi-Fi 回退／USB 保存、静音任务回流和真实两小时静音稳定性检查。
- 完整声学打断／重连、实体触摸、BLE 认证写入、电池及另一台设备的首次安装仍待实物验收；不把代码存在或模拟通过当作实机通过。
