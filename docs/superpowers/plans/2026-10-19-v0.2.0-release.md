# v0.2.0 易安装发行包 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为明确兼容的1.43C提供可核对版本、安装和恢复的公开包。

**Architecture:** 复用构建清单及严格应用槽安装器，新脚本从提交快照和经过验证的镜像组装包；私人文件不参与打包。两次干净构建记录支持可复现性核对，硬件成绩与发布提交绑定。

**Tech Stack:** Python 3.11+、ESP-IDF 6.0.1、SHA-256、现有Node测试与GitHub CI。

**Spec:** [共同设计](../specs/2026-10-19-v0.2.0-companion-experience.md)。

## Global Constraints

- 仅兼容布局＋已确认ota_0；不改引导元数据，不移除源代码绑定检查。
- 不打包账户、网络配置、配对密钥、设备绑定备份、聊天或录音。
- 本任务的发布仅在版本验收完成后进行，不因计划存在自动发布或刷机。

## Review Focus

- 仓库已有忽略文件或符号链接时不能把私人文件装进包（Task 1）。
- 镜像和源码／依赖锁不匹配、摘要损坏必须拒绝（Task 1）。
- 错板型、活动ota_1及未确认OTA不能进入写入（Task 1）。
- 解包到新路径后验证、安装器查找和恢复仍正确（Task 2）。
- 构建不一致、仅静音成绩或单设备结果不能包装成完整验收（Task 2）。

### Task 1: 按提交快照打包

**Files:** 新增 `scripts/package-release.py`、`tests/release_package_test.py`；修改 `tests/hardware-tools.test.mjs`；复用 `firmware/tools/pet_artifacts.py`、`pet_install.py`，不修改它们的保护策略。

**Interfaces:** CLI `python3 scripts/package-release.py --ref <commit> --manifest <json> --out <new-directory>`；输出`source/`（该提交受控源码及安装器要求位置的镜像／源绑定清单）、`SHA256SUMS`、`release.json`、许可清单和中文安装入口。release.json包含version、commit、board、offset、bytes、镜像／源码／依赖摘要、构建版本；不含机器路径。安装用源码根下保留既有`firmware/build/`和`docs/pet-firmware-manifest.json`相对结构。

- [ ] 写失败用例：合成合法受控源码可打包；私人诱饵／符号链接不进入包；坏摘要、错源码、错布局及非空输出目录被拒绝；解包仍可`verify_application`。
- [ ] 运行 `python3 tests/release_package_test.py` 确认断言失败，再实现提交白名单快照与两层清单核对；接入`npm test`，不加载真实凭证或硬件。
- [ ] 重跑安装保护回归和完整测试，提交并独立审查；许可证按实际依赖收集，不能只给顶层许可证。

### Task 2: 干净安装演练与发行门槛

**Files:** 更新 `docs/GETTING_STARTED.zh-CN.md`、`docs/VALIDATION.md`、README中英、CHANGELOG；新增 `docs/releases/v0.2.0.md`、`docs/release-v0.2.0-validation.json`。

**Interfaces:** 消费Task 1输出；验收记录字段至少包含commit、imageSha256、board、buildComparison、install、restore、voice、captions、interaction、limitations，未测项用明确状态，不能默认true。

- [ ] 从相同提交做两次干净构建比较镜像及清单；不一致时定位并记录，不宣称位级复现。
- [ ] 在新路径解包，按中文教程完成无设备验证；检查路径独立、摘要和安装保护，不要求作者私人SDK或目录。
- [ ] 备份与恢复核对后进行同设备应用槽安装／恢复往返；记录每次镜像摘要，保留原有备份不覆盖。
- [ ] 在允许出声的时间做新版中文多轮、上下文、计算、长回答、打断及重连；核对字幕三模式、触摸、脱网互动、休眠与原声音；记录测量，失败项不销项。
- [ ] 更新公开限制；缺第二台设备成绩时继续标注。所有必需检查和独立审查完成后，才准备版本标签、发布包和详细说明。
