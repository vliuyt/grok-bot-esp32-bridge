# v0.2.0 表情互动 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 保留经典粉色圆脸，让宠物对互动和通话状态有可辨认的安静反馈。

**Architecture:** 纯C状态与姿态参数放在pet_core，LVGL只绘制；沿用现有音频／任务状态源。好奇、困惑是本地瞬态，不向Bot伪造情绪或提交任务。

**Tech Stack:** C11、ESP-IDF 6.0.1、LVGL、Node主机测试、ASan/UBSan。

**Spec:** [共同设计](../specs/2026-10-19-v0.2.0-companion-experience.md)。

## Global Constraints

- 基线v0.1.1；1.43C、原生小糖声音、实体BOOT与粉色圆脸保持。
- 不引入额外STT/TTS；夜间不自动播放；本计划不包含刷机。
- 状态不创建音频副作用，旧轮次事件继续被generation/turn隔离。

## Review Focus

- 回答时轻触不能覆盖聆听／说话姿态（Task 1）。
- 断网且静音时也能回应抚摸，不能自动开麦（Task 1）。
- 重复离线事件不能反复触发困惑动画（Task 1）。
- 长等待超时后的过期音频不能重新点亮说话状态（Task 1）。
- 圆屏边缘、设置页和休眠恢复不能出现残影或持续刷新（Task 2）。
