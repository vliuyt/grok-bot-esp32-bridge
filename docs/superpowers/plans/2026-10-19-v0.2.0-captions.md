# v0.2.0 字幕模式 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 设置页提供完整、简洁、关闭三模式，同时保持BOOT语音专用与旧配置可恢复。

**Architecture:** 可移植C字幕策略负责文本边界和模式；NVS独立键保存模式，不扩大现有settings结构。LVGL呈现当前收到的320字节窗口，必要系统提示独立绘制。

**Tech Stack:** C11、ESP-IDF NVS、LVGL、Node/C host tests。

**Spec:** [共同设计](../specs/2026-10-19-v0.2.0-companion-experience.md)。

## Global Constraints

- “完整”指现有输入窗口，不承诺整段回答全文；不增加账号或转写服务。
- captions=false迁移关闭，true迁移简洁；不覆盖Wi-Fi、密钥、音量。
- BOOT手势不变；脱敏导出隐藏对话；不自动刷机。

## Review Focus

- 中英混合、emoji及320字节边界不能产生无效UTF-8（Task 1）。
- 单句过长、无标点或空文本不能越界（Task 1）。
- 旧配置缺键、无效枚举、NVS保存失败必须明确处理（Task 1）。
- 切字幕、断线和新轮次不能重新显示旧文本（Task 2）。
- 字幕关闭时连接／BOOT提示仍可见，完整模式不能吞掉设置上划（Task 2）。

**Interfaces:** `pet_caption_mode_t` = FULL/COMPACT/OFF；`size_t pet_caption_text(pet_caption_mode_t mode,const char *input,char *out,size_t capacity)`返回写入字节数、始终NUL结尾（capacity>0）。`pet_store_caption_mode_load(pet_caption_mode_t *out)`与`pet_store_caption_mode_save(pet_caption_mode_t mode)`返回bool；键`caption_mode`置于已有`grok_pet`，缺键时由旧captions迁移，非法值或I/O失败返回false且不破坏settings。
