# 迭代方向

以下是开放的工作清单，没有完成日期承诺。当前能用和已验证的范围以 README／VALIDATION 为准。

## 优先：可重复的完整验收

- [ ] 完整声学打断、后续提问、断线重连且不重放。
- [ ] 任务结果从设备扬声器读出。
- [ ] 实体触摸、BLE 认证配网、电池与白天主动行为。
- [ ] 第二台设备从干净克隆完成备份、安装、配网及恢复。

## 发行与易用性

- [ ] 从公开源码构建并审计预编译固件、完整许可包与 SBOM。
- [ ] 显式选择 Mac 局域网接口，完善连接诊断。
- [ ] 服务安全升级与卸载、暂停状态持久化。
- [ ] 非默认 OTA 状态或其他布局的受验证迁移路径。

## 宠物体验与功耗

- [ ] 更丰富但安静的本地互动和行为节奏。
- [ ] 困倦／待机独立降低刷新率。
- [ ] 实测电流、唤醒耗时与续航，不用估算代替实测。
- [ ] 保留板级抽象，为其他圆屏板型逐块适配。
